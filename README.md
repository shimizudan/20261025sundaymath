## きっかけの問題

SEIR62 さん（[@seir62](https://x.com/seir62)）の投稿 [make 2026 puzzle！](https://x.com/seir62/status/2106646993196204424) より：

> 1〜9 をこの順で用いて，+，×，( )，数をつなげる操作のみで 2026 を作って下さい。
>
> 例）100 = 1×(2+3)×4+56+7+8+9

「2026 以外の数はどう作れるのか？」が気になったので，Julia ですべての式を調べました。

## わかったこと

| | |
|---|---|
| 1〜9 で作れる値 | **43,350 種類**（最小 44，最大 123456789） |
| 式の総数 | **190,399 通り** |
| 2026 を作る式 | **14 通り**（例：`1+2+34×56+7×(8+9)`） |
| 44 以上で作れない数 | 47, 51, 52, 53, 58，そして **2038**，2062，… |

59 から 2037 まではすべて作れるので，make 20XX puzzle は **2037年まで毎年出題できます**。
2038 は作れません（奇しくも「2038年問題」の年）。

式の数え方：`(1+2)+3` と `1+(2+3)` のように，結合法則でかっこの位置が違うだけの式は同じとみなしています（`1×` をつけるだけの式は別に数えます）。

### 2026 を作る14通りの式

```
1+2+34×56+7×(8+9)              1+(234+5+6+7)×8+9
(12×3×4+5)×(6+7)+89            1+2×(3+4+5+6)×7×8+9
1×2×(3×4×(5+6)×7+89)           1+2×(3+45)×(6+7+8)+9
1+2×(3+4+5)×(6+78)+9           1+(2+3+4×(5+6×7+8))×9
1+((2+3+4×5+6)×7+8)×9          1+2×(3+4)×(5+6+7)×8+9
1+(2+3×4)×(5+6+7)×8+9          1+(2+3)×(45×6+(7+8)×9)
1+((23+4)×5+6×(7+8))×9         1+(((2+3)×4+5+6)×7+8)×9
```

## 方法：区間DP（動的計画法）

どんな式も，最後に行う演算で数字の列が左右の連続した区間に分かれます。
そこで $S(i,j)$ を「数字 $d_i, \ldots, d_j$ から作れる値の集合」とすると

$$
S(i,j) = \{\, d_i d_{i+1}\cdots d_j \,\} \cup \bigcup_{k=i}^{j-1} \{\, a+b,\ a\times b \mid a\in S(i,k),\ b\in S(k+1,j) \,\}
$$

が成り立ちます。これを短い区間から順に計算すると，入れ子のかっこも含めたすべての式を1秒かからずに調べられます。
詳しい説明と 1, 2, 3 での例はノートブックにあります。
